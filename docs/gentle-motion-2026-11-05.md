# Gentle authentication reveals and micro-interactions

Authentication artwork now has a dedicated 1200ms opacity reveal using the shared ease-in-out curve. Both cold and cached images animate after readiness; the old cached-image bypass is removed. A CSS animation establishes the starting opacity even when the image becomes ready before the first painted frame. The preview remains behind the photograph and the form remains usable. Reduced motion shortens the reveal to 120ms.

The welcome now holds for 1600ms, then crossfades into the live library over 800ms, for a 2.4-second sequence. Its greeting enters over 400ms. The cleanup fallback derives its deadline from the CSS tokens, so it cannot cut a longer animation short. Keyboard/pointer skipping, repeat-marker protection, blocked-storage handling and no-JavaScript completion remain. The arrival check is guarded against development Strict Mode ref reattachment.

Micro-interactions keep frequent controls fast and their hit targets stationary. Enabled directional arrows nudge 2px over 160ms on fine-pointer hover. Account menus enter from their trigger with a 4px/0.97-scale transform over 180ms and a 120ms fade; transitions reverse naturally when interrupted. Switch thumbs move over 180ms with coordinated surface feedback. Keyboard input removes the added directional/switch motion and opens menus immediately; reduced motion retains only the menu's brief opacity feedback. Existing press/release, tab marker, save confirmation and copy feedback retain their shared timing.

The auth browser checks sample the image animation at its actual midpoint: opacity is approximately 0.5 at 600ms, including after a cached reload. A real-time welcome test confirms it remains visible beyond the old 1500ms timeout. Additional checks verify fixed button geometry, immediate keyboard feedback and anchored menu timing.

Validation: all 256 unit/database checks and the backup self-test passed. The full browser suite passed 114 cases; the 12 auth/motion cases also passed after the final focus-aware hover refinement. Taste's source and live-browser inspections reported zero failures and zero warnings. The image's cold and cached midpoint, the longer welcome sequence, account menu, and calendar settings were reviewed in both themes at desktop and phone sizes; auth layouts were also checked at 320 and 768px. No dependency or authentication permission change was introduced.
