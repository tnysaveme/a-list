# Weekly releases, hover spacing and tagline

The weekly summary shows three releases initially. When more saved films qualify, “Show all N releases” expands the entire week; “Show fewer releases” restores the preview. Desktop uses additional grid rows and phones retain the horizontally scrollable list. Expansion persists through normal refreshes and resets when the release day changes. Film buttons keep opening their details, and keyboard users can operate the expansion control.

Removed item divider lines and the asymmetric first-item padding. Gaps now separate the items, so rounded hover highlights stand alone. Artwork and arrow feedback still respect fine-pointer and reduced-motion preferences. The shared authentication image caption and library footer now read “Cinema at home”.
