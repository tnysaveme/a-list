# Implemented motion and responsiveness changes

2026-10-28. Implemented and verified locally, then deployed to production with explicit user authorization. No migration, package installation or new runtime dependency. See the [production release record](../docs/motion-production-2026-10-28.md) for staged/live checks, rollback identity and the source-sync readiness warning observed after promotion.

- **Immediate, truthful feedback:** affected save controls expose a pending label/icon immediately. Confirmed membership updates independently of the ancillary list reload. Writes remain serialized and retain the existing read/write/reread reconciliation, uncertainty and Undo safeguards. Filters expose an updating status outside the busy results region, keep the old records visible, and use their committed filter for date labels until replacement succeeds.
- **Collection continuity:** library and catalogue refresh the already loaded range before publishing it atomically, deduplicate IDs, retain the range on a failed later page, preserve server pagination, and restore a visible film anchor in one layout pass. Explicit view/filter/sort replacement still resets paging. A background refresh cannot interrupt an explicit load.
- **Complete overlay lifecycles:** native dialogs keep content, background inertness, scroll lock and focus behavior through their exit. Panel/backdrop fade together. Account uses the shared lifecycle with its busy cancellation guard intact. Radix menu/search layers have managed presence and reversible transitions. Trigger clicks cannot dismiss a reopened menu, and delayed menu focus restoration respects a newly focused search field.
- **Consistent, restrained feedback:** explicit action families use 100ms press / 160ms release at scale 0.97. Independent CSS scale preserves the positioning transform on list save controls. Poster artwork, filters and tabs stay still. Keyboard search is immediate. Reduced motion removes scale/translation and infinite spinner rotation while retaining short opacity feedback and readable state labels.
- **Small finishing improvements:** toast/selection feedback retains content during reversible opacity exits; count/message changes do not replay entry. Synopsis chevrons transition briefly; no speculative content-height animation was added.
- **Measured rendering isolation:** a memoized `MovieCollection`, stable actions and stable membership inputs prevent details-only polling from remapping the background collection. A shared Intl formatter avoids repeated formatter construction per card. Poster `sizes` now follows the actual 640/896/1120px grid breakpoints, 1360px container cap and 56/72px list artwork.

Validation and precise measurement limits are in [baseline-results.md](baseline-results.md). Core implementation plans 001–005 are complete; plan 000 retains the explicit outstanding Safari/device/field profiling work.
